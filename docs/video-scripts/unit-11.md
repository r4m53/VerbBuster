# Lesson 11 — Bellatrix Lestrange's Challenge

## Production guide

- Theme: Harry Potter
- Rival: Bellatrix Lestrange
- BASE forms: blue
- SIMPLE PAST forms: coral
- PAST PARTICIPLE forms: lime
- Keep the highlighted verb on screen while its sentence is narrated.

## Scene 1 — Rival entrance

**Bellatrix Lestrange:** “These verbs will twist and change like dark magic. Keep up, if you can!”

## Scenes 3–10 — Verb training

### 1. SET — SET — SET

- **BASE · blue:** I set the table before dinner.
- **PAST · coral:** Yesterday, I set the table before dinner.
- **PARTICIPLE · lime:** I have set the table before dinner.
- Narration: “set, set, set.”
